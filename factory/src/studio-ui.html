Фабрика

Сток на сайт, рисование для сайта, пины Pinterest и PDF для Amazon KDP. Запуск с кнопки Open Factory.bat.

Кладёт PNG/SVG на сайт: превью, Letter PDF, A4 PDF и текст листа. OpenRouter нужен только для кнопки «Назвать по картинке».

Удобная раскладка папок: 2-3, 3-4, 4-5, 5-6, 6-8. Если папок нет — возраст берётся из поля ниже.

Полный путь к папке на этом компьютере.

Порядок для переделки: подборка Winter → галочка «Только картинки» → «Открыть папку» → дождаться «Сопоставлено» → «Залить». Имена на диске D могут отличаться.

Собирает один PDF интерьера для Amazon KDP из папки SVG/PNG. Срезает стоковую рамку и надпись сайта внизу (host + FREE PRINTABLE), ставит рисунок на 8.5×11. Шрифт титула и подписей — Fredoka. Обложку KDP делает отдельно.

В KDP потом: Paperback → Black & white → trim 8.5" × 11" → Bleed: No Bleed. Пустые обороты помогают, чтобы маркеры не пробивали на следующий рисунок. Подписи — латиница (Bunny, Garden Fox). Один раз нажмите «Назвать по картинке», проверьте список, потом соберите PDF.

Готовый файл обычно лежит в factory\out\kdp\. Это не заливает ничего на сайт.

PDF для скачивания (печать дома)

Идеальный путь: берёшь уже готовый interior PDF с Amazon-сборки — папка с рисунками не нужна. Убираем пустые обороты, добавляем лицо и зад обложки. Размер тот же: 8.5×11.

Сохраняет рядом с исходником как …-download.pdf. Титул и copyright из KDP остаются; пустые страницы после рисунков и pad в конце — выкидываются. Рисунки — лёгкий ч/б JPEG (~200 dpi); обложки (первая/последняя или отдельные файлы) остаются цветными. Файл обычно ~15–30 MB, не 90+. Для Amazon KDP по-прежнему тяжёлый q92.

Или заново из папки SVG/PNG

Если папка с рисунками ещё под рукой — можно собрать download PDF с нуля (без пустых оборотов). Обложки выше тоже подхватятся.

Нужны папка и название выше. Файл: factory\out\kdp\…-download.pdf.

Проверка стиля перед книгой

Считает плотность линий и сравнивает с медианой книги. Можно проверить с учётом уже перерисованных (укажи папку audit ниже). Оригиналы не трогает — новые PNG рядом. Можно задать номера/имена вручную или кинуть отдельную папку картинок «в стиле этой книги».

Не копируй в папку книги файлы вида 47-striped-mitten.png — из‑за них путаются номера. Замены держи только в папке audit.

Обложка Amazon

Один PNG: задник + корешок + лицо, с bleed и плейсхолдерами. Число страниц — из лога после сборки интерьера (например 90), не дели пополам: Amazon считает каждую сторону PDF. Потом Canva / Photopea → PDF в KDP Cover. Официально: kdp.amazon.com/cover-calculator.

Порядок страниц в готовом PDF

Не пересобирает книгу — только меняет местами уже готовые листы. Исходный PDF не затирает: сохраняет …-reordered.pdf. Номера — как в просмотрщике PDF (1 = первая страница).

Тексты для Pinterest

Тема не выбрана

Пишет только заголовки и описания в pins.csv. Картинки пинов (PNG) не пересобирает и не трогает.

По умолчанию заполняет только пустые title/description — как галочка «для новых пинов без текста» при сборке. С галочкой выше перепишет выбранные строки заново.

Счётчики появятся после выбора темы.

Список строится по реальным PNG (включая done/). Без текста отмечены по умолчанию. Строки в pins.csv без картинки не считаются «готовыми».

Убрать квадраты (с сайта, без ИИ)

Берёт letter PDF уже залитый на сайт, срезает рамку/футер и снова кладёт рисунок на весь лист. Исходники не нужны. Тексты не трогает. Бесплатно — модель картинок не вызывается.

Перерисовать выбранные листы

Отметь только те рисунки, которые нужно перегенерировать. Неотмеченные листы останутся без изменений. Каждый выбранный рисунок — платный запрос к модели.
