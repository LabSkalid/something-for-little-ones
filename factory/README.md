# Фабрика Something for Little Ones

Локальная программа на этом компьютере: картинки на сайт, пины в Pinterest, книга Amazon. Сайт сам по себе фабрику не запускает. Картинки на сайт, пины и Amazon — разные вкладки, они не стартуют друг друга.

Адрес: `http://127.0.0.1:4317`  
Запуск: двойной щелчок по `factory\Open Factory.bat`. Окно не закрывать, пока работаете. После обновления кода фабрику закрыть и открыть снова.

Слева — лог. Справа — вкладки. Ключ API лежит в `factory\.env` (файл в git не попадает).

---
| Возраст | Что на листе | Пример |
| --- | --- | --- |
| **3–4** | Одно животное, вокруг пусто | заяц без фона, щенок, лиса |
| **4–5** | Животное **плюс место** — забор, пруд, цветок, холмы | заяц + забор + морковь |
| **5–6** | Уже сцена: лес, подводный сад, несколько зверей | белка среди желудей, курица с цыплятами, заяц с книгой в горах |


## Что где лежит

| Место | Что это |
| --- | --- |
| Папка исходников на диске (`D:\COLORING\…`) | Стоковые или свои рисунки. Фабрика их читает, не удаляет. |
| `site\src\content\themes\` и `site\src\content\sheets\` | Тексты сайта: подборка, листы, возраст, FAQ. Это git. |
| `site\public\print\<тема>\` | PNG превью + PDF Letter и A4 для скачивания. Тяжёлые, **в git не кладутся**. |
| `site\public\pins\` | Картинки пинов 1000×1500: **PNG** (сайт и учёт в фабрике) и **JPEG** (Pinterest). В git только бандлы `*-collection-1.png`. |
| `site\public\pins\pins.csv` | Названия и описания пинов. Пишет фабрика, руками JSON писать не надо. |
| `site\public\pins\done\` | PNG, которые фабрика считает уже опубликованными на Pinterest. В очередь не попадают. |
| Cloudflare R2 (`files.somethingforlittleones.com`) | Интернет-копии: `print/…` и `pins/*.jpg`. Живой сайт картинки скачивания берёт отсюда, не с диска. |
| Таблица Make / Google Sheet | Очередь автопостинга Pinterest. Новые строки добавляет кнопка «В таблицу». |
| `factory\scripts\boards.json` | ID досок Pinterest, порядок тем в очереди, базовые URL. |
| `factory\out\` | Очередь пинов (`pinterest\make-queue.csv`), PDF книг KDP, прочее. Не сайт. |
| `factory\art\` | SVG для консольной сборки `npm run assets` (не вкладка стока). |

Живой сайт — статический Astro. После смены markdown (новые листы, текст подборки) нужна **пересборка/деплой сайта**. Одни только файлы в R2 чинят битые картинки, но не текст страницы.

## Запуск по шагам: картинки на сайт

Вкладка **Картинки на сайт**.

1. Подборка из списка или «Новая подборка» (тогда название, тип, основной возраст).
2. Полный путь к папке с PNG/JPG/WebP/SVG.
3. **Показать картинки.** Карточки сами не отмечаются. Возраст фабрика ставит по папке или имени файла (`2-3`, `3-4`…); если в пути возраста нет — по плотности линий рисунка, без API.
4. Галочка **Взять** только на тех, что писать. Можно «Отметить сопоставленные / все / снять все».
5. **Только картинки** — заменить PNG/PDF у уже существующих URL. Названия листов и текст подборки не трогает. Без галочки — новые листы (уникальный slug), тексты листов, затем описание/возраст/FAQ всей подборки по всем листам темы.
6. **Снять рамку** — срезать стоковый квадрат на исходнике. По умолчанию выкл. С сайта рамку вернуть нельзя: в залитом файле её уже нет.
7. **Записать на сайт** — диск (`content` + `public/print`) и сразу `rclone` в R2 папку `print/<тема>/`.
8. Пересобрать/задеплоить сайт, иначе на somethingforlittleones.com будет старая страница.

Дополнительно на этой вкладке:

| Кнопка | Зачем |
| --- | --- |
| Назвать по картинке | Смотрит рисунок моделью (vision) и заполняет имя, описание, возраст. Платно, текст. |
| Обновить текст подборки | Переписать шапку/FAQ по листам, которые уже на сайте. Без API, картинки не трогает. |
| Выложить картинки в интернет | Повторная заливка `print/<тема>` в R2, если шаг 7 в логе упал. |
| Пины этой темы | Открывает сборку пинов. |
| Уже на сайте → Пересобрать | Letter PDF с сайта снова на лист, без исходника. Рамку стока не вернёт. Без API. |

## Запуск по шагам: пины

Вкладка **Пины**. Картинки пинов фабрика рисует из уже залитых листов (локально, Sharp), не вызывает модель картинок.

1. У темы **1. Собрать пины** — PNG + JPEG 1000×1500 в `site\public\pins`. Можно бандлы (по 3–4 листа), одиночные или оба. Строки в `pins.csv` появляются сами.
2. **2. Тексты** — заголовки и описания для Pinterest (текстовая модель). Можно пропустить.
3. **3. В таблицу** у этой темы:
   - дописывает пустые тексты пинов этой темы (текстовая модель, только пустые поля);
   - сжимает новые JPEG, если PNG новее;
   - `rclone` JPEG пинов в R2 `pins/`;
   - `rclone` всех print-файлов в R2 `print/` (на случай, если листы ещё не уехали);
   - собирает очередь и шлёт **новые** строки в таблицу Make. Уже лежащие (тот же файл) не дублирует.

**Все новые пины в таблицу** — то же по всем темам. Для одной темы жмите её «3», иначе снова прогонятся все старые сезонные, которые таблица уже знает.

PNG пина нужен сайту (превью коллекции, картинка для соцсетей: `/pins/<тема>-collection-1.png`) и фабрике (учёт, `pins.csv`). JPEG уходит на Pinterest через `https://files.somethingforlittleones.com/pins/….jpg`.

Пины в корне `pins\` считаются «ещё не на Pinterest». Лежат в `pins\done\` — очередь их пропускает. Перенос в `done` фабрика сама не делает: это после того, как пин реально ушёл в Pinterest (вручную или вашим процессом).

## `boards.json` — что можно менять

Файл: `factory\scripts\boards.json`. То же ID доски можно вписать в поле на вкладке Пины → «Сохранить доску» (фабрика перепишет этот файл).

```json
{
  "siteBase": "https://somethingforlittleones.com",
  "imageBase": "https://files.somethingforlittleones.com/pins",
  "themes": [
    { "key": "thanksgiving", "board": "thanksgiving", "boardId": "1086000966335597727", "tier": 1, "weight": 3 }
  ]
}
```

| Поле | Смысл |
| --- | --- |
| `siteBase` | База ссылок в пине (страница на сайте). |
| `imageBase` | База URL картинки в таблице. Должна совпадать с публичным CDN пинов. |
| `key` | Короткое имя темы **без** `-coloring-pages` (`animal`, `winter`). Файлы пинов: `animal-coloring-pages-….png`. |
| `board` | Подпись доски в очереди (обычно то же, что `key`). |
| `boardId` | Цифры из ссылки доски Pinterest. Пусто — строка в таблицу всё равно попадёт, Make не знает куда постить. ID **на тему**, не на каждый пин. Старые строки в таблице свой ID не подставляют новым. |
| `tier` | Меньше число — раньше в перемешанной очереди (сезон = 1, обычные чаще 2). |
| `weight` | Сколько пинов этой темы брать за один проход перемешивания. |

Тема, которой нет в списке, при сборке очереди добавится сама с пустым `boardId`. Чтобы Make постил, ID всё равно нужен.

Правило: `boardId` — только цифры.

## Хранилище (R2) — из фабрики и снаружи

Публичный адрес файлов: `https://files.somethingforlittleones.com/`  
Команда загрузки: **rclone** (программа Windows). Удалённое имя по умолчанию `r2`, бакет `sfl-files`. Задаются в `factory\.env`: `R2_REMOTE`, `R2_BUCKET`.

### Что заливает фабрика

| Когда | Куда в бакете | Какие файлы |
| --- | --- | --- |
| «Записать на сайт» | `print/<тема>/` | PNG + PDF этой темы |
| «Выложить картинки в интернет» | `print/<тема>/` | то же, повтор |
| «В таблицу» (пины) | `pins/` только `/*.jpg` | JPEG пинов из корня `public\pins` |
| «В таблицу» (пины) | `print/` целиком | все листы скачивания |

PNG пинов в R2 фабрика **не** грузит. На живом сайте превью коллекции обычно из деплоя `public/pins/*-collection-1.png` (это как раз то, что git хранит).

### Снаружи фабрики, тем же rclone

В корне репозитория: **`publish.bat`**

1. Сжимает новые пины в JPEG (`publish-pins.ps1`).
2. `rclone copy D:\KIDS\site\public\pins r2:sfl-files/pins --include "/*.jpg"`
3. `rclone copy D:\KIDS\site\public\print r2:sfl-files/print`

Имеет смысл, если фабрика не запущена, заливка в логе упала, или нужно догнать диск с R2 без таблицы Make.

Вручную (PowerShell), те же папки:

```text
rclone copy "D:\KIDS\site\public\print" r2:sfl-files/print --progress
rclone copy "D:\KIDS\site\public\pins" r2:sfl-files/pins --include "/*.jpg" --progress
```

Одна тема:

```text
rclone copy "D:\KIDS\site\public\print\animal-coloring-pages" r2:sfl-files/print/animal-coloring-pages --progress
```

Проверка, что файл в интернете: открыть  
`https://files.somethingforlittleones.com/print/<тема>/<slug>.png`

Локальный просмотр сайта (`npm run dev` в `site\`) картинки скачивания берёт с диска `/print`. Сборка продакшена указывает на CDN.

## Таблица Make

Нужны `SHEET_WEBHOOK_URL` и `SHEET_WEBHOOK_TOKEN` в `factory\.env`. Без URL фабрика только пишет `factory\out\pinterest\make-queue.csv` и `.json`, в таблицу не шлёт.

Каждая новая строка: имя файла, `board`, `board_id`, `image_url` (JPEG на CDN), title, description, link, status `ready`. Make читает таблицу и постит. Дубли по уже известным файлам отсекает вебхук (`added` / `skipped` в логе).

## Что стоит денег (OpenRouter)

Ключ: `OPENROUTER_API_KEY` в `factory\.env`.

Модели (можно сменить в том же файле):

| Переменная | Зачем | По умолчанию |
| --- | --- | --- |
| `OPENROUTER_IMAGE_MODEL` | Новые рисунки с нуля | `openai/gpt-image-2` |
| `OPENROUTER_IMAGE_QUALITY` | Качество картинки | `medium` |
| `OPENROUTER_EDIT_IMAGE_MODEL` | Правка существующей картинки | `openai/gpt-image-1` |
| `OPENROUTER_TEXT_MODEL` | Тексты (пины, план книги, мета) | `google/gemini-2.5-flash` |
| `OPENROUTER_VISION_MODEL` | Посмотреть картинку и назвать | тот же текстовый, если не задан |

Картинки (дорого) ≫ vision/текст (дешево).

### Платно — картинка (генерация)

- Вкладка **Рисовать** → «Нарисовать новые», «Перерисовать», «Перерисовать все».
- Вкладка **Нарисовать книгу** → генерация страниц (план — отдельно, текст).
- Консоль: `npm run produce`, `npm run redraw`.
- KDP **аудит со включённой перерисовкой**, «Дорисовать оставшиеся», «Перерисовать указанные», чужие картинки «в стиле книги».

Каждый лист = отдельный запрос к модели картинок.

### Платно — текст / vision (дешевле, без новой картинки)

- «Назвать по картинке» на импорте стока.
- KDP «Назвать по картинке».
- Пины «2. Тексты» и автодопись пустых текстов на «3. В таблицу».
- План сюжетов книги (шаг 1).
- KDP аудит **без** галочки перерисовки — только смотрит плотность/стиль (vision), оригиналы не трогает.

### Бесплатно — только этот компьютер (Sharp, PDF, rclone, markdown)

- Показать картинки, подобрать возраст по папке/линиям.
- Снять рамку, вписать на letter, футер сайта, PNG/PDF.
- Записать на сайт + залить print в R2.
- Обновить текст подборки по списку листов.
- Пересобрать лист с сайта («Убрать квадраты» / «Уже на сайте»).
- Собрать пины (картинки 1000×1500).
- Сжать JPEG, залить pins/print, очередь, строки в таблицу (кроме дописи пустых текстов).
- Собрать PDF KDP, download PDF, шаблон обложки, переставить страницы.
- Заменить файл листа готовой картинкой с диска.

Импорт стока **без** «Назвать по картинке» API не вызывает. Тексты листов тогда из имени файла; подборки — шаблон по названиям листов.

## Другие вкладки (кратко)

**Книга Amazon** — не сайт. Папка SVG/PNG → PDF 8.5×11 в `factory\out\kdp\`. Пустые обороты для KDP, без футера сайта. Обложка — шаблон PNG, не заливка в Amazon.

**Нарисовать книгу** — план (текст) + генерация PNG в `factory\out\books\…`, потом PDF во вкладке Amazon.

**Рисовать** — новые страницы на сайт через модель; «Убрать квадраты» бесплатно.

Консоль из `factory\`: `npm run studio` то же, что bat. Ещё: `npm run pins`, `npm run produce`, `npm run kdp` — см. `factory\src\cli.ts`.

## Типичные сбои

| Что видно | Что сделать |
| --- | --- |
| На сайте пустые карточки, файлы на диске есть | Не уехало в R2. «Выложить картинки в интернет» или `publish.bat`. |
| Текст подборки старый | Листы писали с «Только картинки», либо сайт не пересобрали. «Обновить текст подборки», затем деплой. |
| Таблица: добавлено 0, уже были N | Жали общую кнопку, в очередь попали старые темы. «3. В таблицу» у нужной темы. |
| Очередь без пинов / «нет свежего JPG» | Нет пары JPEG или он старше PNG. Снова «В таблицу» (сожмёт) или `publish.bat`. |
| Строки в таблице, Pinterest молчит | Пустой `boardId` у темы. |
| Нет rclone | Установить rclone, в `.env` remote/bucket, перезапуск Windows, снова фабрика. |
| Нет OPENROUTER_API_KEY | Только платные кнопки упадут; импорт стока без vision работает. |
